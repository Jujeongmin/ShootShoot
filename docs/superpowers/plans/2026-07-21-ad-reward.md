# 광고 보상 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 메인 메뉴에서 "광고 보상" 화면을 열어 광고를 보고 골드 30개를 받을 수 있게 한다. 바주카는 "준비 중" 잠긴 카드로만 보여준다. 실제 Verse8 광고 SDK는 아직 없으므로 항상 성공하는 스텁으로 구현한다.

**Architecture:** 새 순수 모듈 `adSdk.js`가 `showRewardedAd() -> Promise<boolean>` 스텁을 제공한다(짧은 지연 후 항상 `true`). 새 UI 모듈 `adRewardPanel.js`가 `settingsPanel.js`/`shopPanel.js`와 동일한 오버레이 패턴으로 "골드 30개 받기" 버튼(클릭 시 비활성화+문구 변경)과 "바주카" 잠긴 카드, "닫기" 버튼을 렌더링한다. `screens.js`의 `showMenu`가 광고 보상 버튼용 콜백을 하나 더 받도록 확장된다. `game.js`는 `openAdRewardFromMenu`/`closeAdReward`/`watchAdForGold` 핸들러를 추가한다 — `openShopFromMenu`/`closeShop` 패턴을 그대로 따르되, 광고 시청 완료(스텁 resolve) 시 골드를 지급하고 자동으로 메뉴로 복귀한다.

**Tech Stack:** Vanilla JS ES 모듈, Vitest(순수 함수 테스트, 가짜 타이머 사용), DOM 렌더링(기존 패턴 재사용, 신규 의존성 없음).

## Global Constraints

- TypeScript 사용 안 함 — 순수 JS ES 모듈만 사용.
- 광고 시청 완료 시 골드 30개 지급 — `CONFIG.adReward = { goldAmount: 30 }`.
- 하루 시청 횟수 제한 없음 — 쿨다운/카운트 상태를 추가하지 않는다.
- 바주카는 실제로 구현하지 않음 — 잠긴 카드로만 표시, 클릭 불가.
- `showRewardedAd()`는 이번 범위에서 항상 성공(`true`)만 반환한다 — 실패/스킵 분기는 만들지 않는다.
- 플레이 중 광고 보상 접근(단축키 등)은 만들지 않음 — 메인 메뉴에서만 진입.

- [ ] **Step 1: `game/src/ui/adRewardPanel.js` 작성**

```js
export function createAdRewardPanel(container) {
  const overlay = document.createElement('div');
  overlay.style.cssText = `
    position: absolute; inset: 0; display: none; flex-direction: column;
    align-items: center; justify-content: center; color: #fff;
    font-family: sans-serif; background: rgba(0,0,0,0.7); z-index: 25;
  `;
  container.appendChild(overlay);

  function lockedCard(label) {
    const el = document.createElement('div');
    el.textContent = label;
    el.style.cssText = `
      margin: 8px; padding: 16px 24px; border-radius: 6px; min-width: 160px;
      text-align: center; background: rgba(255,255,255,0.1); color: #888;
      border: 1px solid #555;
    `;
    return el;
  }

  function show(onClose, onWatchAd) {
    overlay.innerHTML = '';

    const title = document.createElement('h2');
    title.textContent = '광고 보상';
    overlay.appendChild(title);

    const list = document.createElement('div');
    list.style.cssText = 'display: flex; flex-direction: row;';

    const goldBtn = document.createElement('button');
    goldBtn.textContent = '골드 30개 받기';
    goldBtn.style.cssText = `
      margin: 8px; padding: 16px 24px; font-size: 16px; cursor: pointer;
      border: none; border-radius: 6px; background: #f0a500; color: #1a1a2e; min-width: 160px;
    `;
    goldBtn.addEventListener('click', () => {
      goldBtn.disabled = true;
      goldBtn.textContent = '광고 재생 중...';
      onWatchAd();
    });
    list.appendChild(goldBtn);
    list.appendChild(lockedCard('바주카'));
    overlay.appendChild(list);

    const closeBtn = document.createElement('button');
    closeBtn.textContent = '닫기';
    closeBtn.style.cssText = `
      margin-top: 16px; padding: 10px 24px; font-size: 18px; cursor: pointer;
      border: none; border-radius: 6px; background: #f0a500; color: #1a1a2e;
    `;
    closeBtn.addEventListener('click', onClose);
    overlay.appendChild(closeBtn);

    overlay.style.display = 'flex';
  }

  function hide() {
    overlay.style.display = 'none';
  }

  return { show, hide };
}
```
