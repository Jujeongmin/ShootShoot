# ShootShoot — 로우폴리 원숭이 저격 슈터 (설계 문서)

- **날짜**: 2026-07-16
- **참고 게임**: [ShootZ (Poki, NoPowerup)](https://poki.com/kr/g/shootz) — 3D HTML5 정밀 저격 슈터. 마우스 홀드로 조준, 릴리즈로 발사. 한 발로 여러 타겟 관통(one-shot-multi-hit), 하이스코어 추구. 싱글플레이.
- **배포 대상**: [Verse8 / Agent8](https://docs.verse8.io/ko/docs) 플랫폼 (Vite 기반 클라이언트 프로젝트로 업로드)

## 1. 목표 (What & Why)

ShootZ의 핵심 재미 — **"조준 홀드 → 릴리즈 발사"의 단순 조작**과 **원샷 멀티히트 정밀 사격, 하이스코어 경쟁** — 을 재현하되, 타겟을 **까부는 로우폴리 원숭이**로 바꿔 고유한 성격(personality)과 코믹함을 더한다. 3D이되 Three.js 프리미티브 조합으로 가볍게 구현하여 외부 에셋 없이 완전 self-contained.

**성공 기준**
- `game/index.html` 진입점의 표준 Vite 프로젝트로 빌드/실행되어 Verse8에 업로드 가능.
- 마우스 홀드-조준 / 릴리즈-발사로 원숭이 타겟을 맞히고, 관통·헤드샷·콤보 점수가 집계된다.
- 라운드 진행에 따라 난이도가 상승하고, 게임오버 시 최고점수가 저장(localStorage)된다.
- 순수 로직(점수/난이도/명중 해석)이 Vitest 유닛 테스트로 검증된다.

## 2. 비목표 (YAGNI)

- 멀티플레이 / Verse8 게임서버 SDK (싱글플레이이므로 v1 제외).
- 결제(VXShop) / 광고 모듈.
- 외부 에셋(3D 모델, 이미지, 오디오 파일) — 전부 프리미티브 + WebAudio 합성.
- 계정/랭킹 서버 (하이스코어는 로컬 저장).

## 3. 기술 스택

| 영역 | 선택 | 비고 |
|------|------|------|
| 번들러 | **Vite** (바닐라 JS) | Verse8 표준 구조 |
| 3D | **Three.js** (npm) | ES 모듈 import |
| 오디오 | **Web Audio API** | 효과음 합성, 에셋 없음 |
| UI | HTML/CSS DOM 오버레이 | HUD·메뉴·게임오버 |
| 테스트 | **Vitest** | 순수 로직 유닛 테스트 |
| 언어 | JavaScript (ES modules) | 단순성 우선, TS 미도입 |

## 4. 프로젝트 구조

```
ShootShoot/
├─ package.json           # 루트. scripts: dev / build / preview / test
├─ vite.config.js         # root: 'game', build.outDir: '../dist'
├─ vitest.config.js       # 순수 로직 테스트 설정
├─ game/                  # ← Vite root
│  ├─ index.html          # 진입점. <script type="module" src="/src/main.js">
│  └─ src/
│     ├─ main.js          # 부트스트랩: 엔진 생성 + 게임 시작
│     ├─ config.js        # 튜닝값 (점수/타이머/난이도 커브/색상)
│     ├─ core/
│     │  ├─ engine.js     # 렌더러·씬·카메라·라이팅·리사이즈·렌더 루프(delta tick)
│     │  └─ input.js      # 마우스 이동(조준) + 홀드/릴리즈(발사) 이벤트 추상화
│     ├─ gameplay/
│     │  ├─ world.js      # 환경: 떠 있는 플랫폼, 스카이 색, 조명
│     │  ├─ monkey.js     # 원숭이 타겟(메시 조립 + 아이들/도발/피격 애니 + 명중 파트별 판정)
│     │  ├─ targetManager.js # 스폰/디스폰, 웨이브 배치, 난이도 반영, 이동 업데이트
│     │  ├─ shooting.js   # 레이캐스트 발사 → 관통 멀티히트 해석(순수 판정 함수 분리)
│     │  ├─ scoring.js    # 점수·콤보·배율·최고점수 persistence (순수 함수 + 저장 어댑터)
│     │  └─ game.js       # 상태머신(menu/playing/gameover), 라운드 흐름, 전 모듈 배선
│     ├─ audio/
│     │  └─ sfx.js        # WebAudio 합성: shoot/hit/headshot/combo/miss/roundClear
│     └─ ui/
│        ├─ hud.js        # 점수·콤보·타이머·라운드 표시
│        └─ screens.js    # 메인메뉴 / 게임오버(점수·최고점수·재시작)
└─ test/
   ├─ scoring.test.js
   ├─ difficulty.test.js
   └─ shooting.test.js
```

**Vite 설정 핵심**: `vite.config.js`는 루트에 두고 `root: 'game'` 지정 → `game/index.html`이 진입점. `build.outDir`를 `'../dist'`로 하여 산출물은 루트 `dist/`. package.json도 루트에 위치해 Verse8이 표준 Vite 프로젝트로 인식.

## 5. 핵심 게임플레이

### 5.1 시점 / 월드
- **1인칭 저격 시점**: 고정 위치 카메라 + 아주 미세한 흔들림(sway). 정면에 떠 있는 로우폴리 플랫폼들이 원근으로 배치되고 그 위에 원숭이가 선다.
- 배경은 단색/그라디언트 스카이 + 반구 조명(hemisphere) + 방향광으로 로우폴리 톤.

### 5.2 조준 / 발사
- 마우스 이동 → 조준 방향(크로스헤어) 갱신.
- **좌클릭 홀드 = 조준 상태**: 스코프 오버레이 표시 + 카메라 FOV 살짝 줌인, 미세 흔들림 감소(정밀).
- **릴리즈 = 발사**: 카메라에서 크로스헤어 방향으로 **레이캐스트**.
- 발사 쿨다운(연사 제한) 및 발사 SFX.

### 5.3 명중 판정 (원샷 멀티히트)
- 발사 레이가 통과하는 원숭이들을 거리순으로 수집 → **관통 히트**로 처리.
- 각 원숭이는 **머리(head) / 몸통(body)** 파트로 판정: 머리 = **헤드샷 보너스**, 몸통 = 기본.
- 관통한 원숭이 수 = **콤보 배율** (2관통·3관통…).
- 아무도 못 맞히면 **미스**(스트릭 초기화 + 미스 카운트 증가).
- `shooting.js`의 **해석부는 순수 함수**로 분리: 입력(정렬된 히트 목록: {monkeyId, part, distance}) → 출력(점수 이벤트, 콤보 배율). 렌더/레이캐스트(부수효과)와 분리하여 테스트.

### 5.4 원숭이 타겟 (까부는 컨셉)
- **조립(프리미티브)**: 몸통(캡슐) + 머리(구) + 둥근 귀 2개 + 밝은 얼굴판/주둥이 + 휘어진 꼬리. 갈색 몸 + 살구색 얼굴.
- **아이들 애니메이션**: 위아래 깐족 바운스, 가끔 좌우 흔들·팔 흔들기·고개 갸웃.
- **도발 모션**: 랜덤하게 플레이어 쪽 보며 약올리는 제스처(머리 흔들기/짧은 점프).
- **피격 반응**: 과장되게 뒤로 튕기며 회전 + 코믹 "삑!" SFX. 헤드샷은 반응/점수 더 큼.
- 각 원숭이는 `update(dt)`로 자기 애니메이션을 갱신, 명중 시 `hit(part)`로 반응/제거 상태 진입.

## 6. 진행 · 점수

### 6.1 라운드 흐름
- 라운드마다 `targetManager`가 난이도 커브에 따라 원숭이 배치(수/거리/크기/이동)를 스폰.
- 배치의 원숭이를 전부 처치하면 **라운드 클리어** → 짧은 연출/SFX → 다음 라운드(난이도↑).
- **난이도 커브(순수 함수)**: 라운드 번호 → {원숭이 수, 이동 속도/폭, 크기 스케일, 제한시간}. `config.js` 파라미터로 튜닝, `difficulty.test.js`로 단조 증가 검증.

### 6.2 점수 규칙
- 기본 명중 점수 + 헤드샷 보너스 + 관통 배율(관통 수) + 연속 명중 스트릭 배율.
- **최고점수 localStorage 저장** (`scoring.js`의 저장 어댑터, 키: `shootshoot.highscore`). 저장 로직은 인터페이스로 주입해 테스트에서 목킹.

### 6.3 종료 조건
- 라운드 제한시간 초과 **또는** 미스 한도 초과 → **게임오버**.
- 게임오버 화면: 최종 점수 / 최고점수 / 재시작 버튼.

## 7. 폴리싱
- **파티클**: 명중 시 로우폴리 버스트 + 화면상 점수 팝업(관통/헤드샷 강조).
- **SFX(WebAudio 합성)**: shoot, hit, headshot, combo, miss, roundClear.
- **UI**: 메인메뉴(시작) / HUD(점수·콤보·타이머·라운드) / 게임오버.
- **조준 연출**: 스코프 오버레이 + FOV 줌.

## 8. 모듈 경계 & 테스트 전략

| 계층 | 모듈 | 테스트 |
|------|------|--------|
| 순수 로직 | `scoring`(배율/합산), `difficulty 커브`, `shooting` 히트 해석 | **Vitest 유닛 테스트** (부수효과 없음, 주입식 저장소) |
| 부수효과 | `engine`, `input`, `world`, `monkey`(렌더), `audio` | 수동/브라우저 확인 |
| 배선 | `game`(상태머신) | 상태 전이는 순수화 가능한 부분만 테스트 |

각 모듈은 **하나의 책임**을 갖고 잘 정의된 인터페이스로 통신한다:
- `engine`: 렌더 루프와 tick 콜백 제공 → 게임플레이는 렌더 API 몰라도 됨.
- `input`: 원시 마우스 이벤트를 "조준 방향 / 발사 트리거"라는 의미 이벤트로 변환.
- `shooting`: 레이캐스트 결과(부수효과)와 점수 해석(순수)을 분리.
- `scoring`: 저장은 주입된 어댑터를 통해서만 → 테스트 시 인메모리 목.

## 9. 열린 위험 / 결정
- Verse8의 정확한 업로드/빌드 커맨드 규약은 문서상 프롬프트 기반 설명 위주 → 표준 Vite 산출물(`dist/`)이면 호환된다는 가정. 업로드 단계에서 검증 필요.
- 프리미티브만으로 "원숭이다움"을 얼마나 낼지는 반복 조정 대상(우선 실루엣·색·애니메이션으로 전달).
- Git: 현재 폴더는 git 저장소가 아님 → 필요 시 `git init` 후 이 문서 커밋.
