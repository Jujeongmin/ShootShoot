# 스코프 조준 카메라 & UI (설계 문서)

- **날짜**: 2026-07-20
- **선행 작업**: [2026-07-20-rifle-viewmodel-design.md](2026-07-20-rifle-viewmodel-design.md)
- **실행 순서**: 원숭이 FBX + 저격총 뷰모델 계획이 모두 끝난 뒤 구현한다(`game.js`를 또 수정하므로).

## 1. 목표

지금은 조준(마우스 홀드) 중에도 카메라가 전혀 움직이지 않고, FOV만 좁아지는 "줌"만 있다. 이를 실제 스코프처럼 바꾼다: 조준 중 마우스를 움직이면 카메라가 그 방향으로 실제로 회전하고(제한된 범위 내), 화면에는 스코프 렌즈 느낌의 원형 비넷 + 중앙 레티클 UI가 나타난다. 사격 판정은 화면 정중앙(레티클 위치)을 기준으로 한다.

## 2. 아키텍처

### 2.1 조준 카메라 회전

- 조준 시작(마우스 다운) 시점부터, 매 프레임 현재 마우스의 화면 중심 기준 정규화 오프셋(NDC, 이미 `input.getNdc()`로 얻고 있음)에 비례해 카메라의 `rotation.y`(좌우)/`rotation.x`(상하)를 설정한다.
- 회전 범위는 상수로 제한한다: 초기값 **좌우(yaw) ±0.3 rad(약 17도), 상하(pitch) ±0.2 rad(약 11도)** — 정확한 느낌은 구현 중 실제로 조준해보며 조정.
- 조준을 풀면(마우스 업, 발사 시점) 카메라 회전을 즉시 `(0, 0, 0)`으로 되돌린다(부드러운 보간은 이번 범위 밖 — YAGNI).

### 2.2 발사 판정 — 항상 화면 중앙 기준

- `handleShot`은 더 이상 발사 시점의 마우스 NDC 좌표를 받지 않는다. 대신 항상 `raycaster.setFromCamera({x: 0, y: 0}, engine.camera)`로 쏜다 — 카메라가 조준 중 회전해 있으므로, 화면 중앙(레티클)이 곧 실제 조준 방향이다.
- `input.onAimUp(handleShot)`의 콜백 시그니처가 바뀐다(더 이상 ndcX/ndcY를 안 받음) — `input.js` 자체는 수정하지 않고(여전히 콜백에 좌표를 넘겨주지만), `game.js`가 그냥 그 인자를 안 쓰면 된다.

### 2.3 스코프 UI

- 새 모듈 `game/src/ui/scopeOverlay.js`: `createScopeOverlay(container) -> { show(), hide() }`.
- **비넷(화면을 검게 가리는 효과)은 없다** — 스코프 밖도 안도 게임 화면이 그대로 보인다. 대신 화면 정중앙에 원형 링 테두리(검정 4px border, 내부 투명) + 듀플렉스 스타일 십자선(위/아래/좌/우 4개의 선분이 중앙까지 닿지 않고 중간에 갈라진 형태) + 중앙의 빨간 점을 오버레이로 그린다(사용자가 제공한 레퍼런스 스코프 레티클 이미지 기준).
- 조준 시작 시 `show()`, 조준 해제 시 `hide()` — 기존 `input.isAiming()` 폴링 지점(지금 FOV/총 가시성을 처리하는 곳)에 같이 추가한다.

### 2.4 총(뷰모델)과의 관계

- 기존 동작 그대로 유지: 조준 중엔 총 뷰모델이 숨겨지고(스코프 UI가 화면을 채움), 조준 해제 시 총이 다시 보인다.

## 3. 인터페이스 변경 요약

- `game/src/ui/scopeOverlay.js` (신규): `createScopeOverlay(container) -> { show(), hide() }`.
- `game/src/gameplay/game.js`: `handleShot`이 인자를 받지 않는 형태로 변경(내부적으로 항상 화면 중앙 레이캐스트). 틱 루프에서 조준 중 카메라 회전 적용 + 스코프 오버레이 show/hide 추가.

## 4. 비목표 (YAGNI)

- 조준 해제 시 카메라 복귀 애니메이션(부드러운 보간)은 만들지 않음 — 즉시 복귀.
- 스코프 배율(줌 단계 여러 개), 스코프 흔들림(호흡에 따른 미세 떨림) 등은 만들지 않음.
- 조준 카메라 회전 범위를 상황(라운드, 난이도)에 따라 바꾸는 기능은 만들지 않음 — 고정값.

## 5. 열린 위험

- 회전 범위(±0.3/±0.2 rad)는 초기 추정값 — 실제로 조준해보며 "너무 좁다/너무 넓다" 느낌을 확인해 조정이 필요하다.
- 스코프 비넷의 정확한 크기/부드러움(가장자리 페더링 정도)도 시각적으로 조정이 필요한 부분이다.
